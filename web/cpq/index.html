    Pourquoi des règles · Et pas un tableur
    
      
    Ce qu’un configurateur change pour vous
    
    
    
    
      
      
    • Le prix ne dépend plus de qui vend
      Les tarifs, remises et taxes sont écrits une fois. Deux vendeurs, deux régions, le même devis.
      Preuve : changez la quantité ci-dessus, la remise se déclenche seule aux paliers 5, 10 et 25.
      • 
      
    • Les incompatibilités sont attrapées avant la commande
      Une option qui en exclut une autre, une option qui en exige une autre, une dimension minimale : la règle tranche et l’explique.
      Preuve : cochez le plateau inclinable avec le tiroir, ou le deuxième plateau sous 140 cm.
      • 
      
    • Chaque décision a une trace
      Le devis liste les règles appliquées, en français. Le client comprend, le service à la clientèle aussi.
      Preuve : la liste « Ce que les règles ont décidé », copiée avec le devis.
      • 
      
    • Le même moteur, dans votre outil
      Ces règles vivent dans une fonction sans dépendance ; elles se branchent sur un site, une application, un ERP (Sage X3) ou une API.
      Preuve : le code affiché sous le devis est celui qui vient de calculer votre total ; voir aussi la démonstration 05.
