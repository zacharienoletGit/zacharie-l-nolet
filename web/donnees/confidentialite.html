Confidentialité · Site Données

Ce site ne collecte rien

Mis à jour le 21 septembre 2026.

Ce que le site collecte

Aucune donnée personnelle. Il n’y a ni compte, ni formulaire envoyé à un serveur, ni infolettre. Les nombres que vous tapez dans les démonstrations sont calculés dans votre navigateur et disparaissent quand vous fermez la page : ce site n’écrit rien dans le stockage de votre navigateur et n’utilise aucun témoin.

Aucune intelligence artificielle sur vos données

Aucun service d’intelligence artificielle ne reçoit ce que vous tapez. Les calculs sont des fonctions écrites à la main, affichées sur la page.

Tiers

Le site est hébergé par GitHub Pages, qui tient des journaux d’accès techniques (adresse IP, page demandée, date) selon sa propre politique. Aucun autre tiers ne reçoit de données : aucun script externe, aucune police externe, aucune mesure d’audience.

Le bouton « Copier le devis »

Sur le site CPQ, il copie le texte du devis dans votre presse-papiers, à votre demande seulement. Rien n’est envoyé nulle part.
