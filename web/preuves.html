Le code affiché est le code qui tourne

Chaque source à gauche est lue au chargement par Function.prototype.toString : c’est la fonction qui s’exécute à droite. Les trois premières sont portées telles quelles du TypeScript du dépôt ; les trois autres sont écrites pour cette page, dans le même esprit. Modifie les entrées.

Recherche sans accents

Un lecteur tape quebec, Netari ou ETOILE : la requête et le texte sont décomposés (NFD), dépouillés de leurs diacritiques, puis comparés. Le test du dépôt vérifie que « Netari » ne trouve rien et que « nectari » trouve l’essai.

        02
        
    Édition déterministe
    
        
    Quand le catalogue n’a pas dix rangs pour une date, l’application ne tire pas au hasard : elle hache date:id avec FNV-1a 32 bits et prend les dix plus petits scores. Même date, même édition, sur n’importe quel appareil. Change la date : l’édition change, puis revient.

      File idempotente et fusion last-write-wins
      
        
      Hors-ligne, chaque geste devient une opération. Découper deux fois le même texte ne crée pas deux opérations : la file remplace. À la synchronisation, la note la plus récente gagne, que ce soit l’appareil ou le serveur. L’appareil reste la vérité tant qu’il est plus récent.

        04
        
        Un ratio ne se somme pas
        
        
        Trois régions, un taux de livraison à temps chacune. La moyenne des taux et le taux global ne sont pas le même nombre dès que les volumes diffèrent. Dans Power BI, la mesure est DIVIDE(SUM(à temps), SUM(total)), jamais AVERAGE(taux). Change un volume et regarde l’écart bouger.

        05
        
        CPQ : les règles avant l’écran
        
        
        Un configurateur d’exemple (un pupitre de lecture, prix fictifs). Les règles forment un graphe de contraintes : une option en exclut une autre, une autre en exige une troisième, une remise se déclenche sur un seuil. Le prix n’est jamais saisi ; il est déduit, et chaque règle affiche son état. Coche le plateau incliné : la lampe tombe, parce que le tiroir qu’elle exige est exclu.

        06
        
          Export Markdown du classeur
          
        
          Le classeur de l’application s’exporte vers Fichiers en Markdown lisible sans l’application. Ici, une fonction sœur rend tes feuilles d’essai : écris-en une, retire-en une, et regarde le texte se réécrire. La mémoire n’appartient pas à un format propriétaire. Les feuilles restent dans ton navigateur.
