Stage, contrat ou mandat

  • Stage de fin de DEC

    Dans votre équipe de développement ou de données. J’arrive avec du code public et des tests qui passent.

Ma méthode · Appliquée à ce site

Ma liste de vérification avant la mise en ligne

Quatre listes passées avant chaque mise en ligne. Ce site les a passées.

  • Un vrai site, pas une maquette

    Page d’erreur, bouton d’action visible sans défiler, titre et description pour chaque page, image de partage pour les réseaux, icônes, plan du site, texte de remplacement sur chaque image, affichage mobile, messages d’erreur clairs dans les formulaires, page de remerciement, politique de confidentialité, conditions, vraie adresse de contact.

  • Sécurité avant la mise en ligne

    Aucun mot de passe ni clé dans le code, vérifications faites côté serveur, chaque utilisateur ne voit que ses données, entrées validées, protection contre les injections et les scripts malveillants, connexion chiffrée obligatoire, dépendances vérifiées contre les failles connues.

  • Le légal qui vous protège

    Une politique de confidentialité qui dit ce qui est collecté et par qui, la suppression des données sur demande, aucun stockage public, aucun faux témoignage, une résiliation aussi simple que l’inscription.

  • Une identité, pas un gabarit

    Pas de dégradés criards, pas de texte de remplissage, pas d’icônes génériques : une typographie choisie, des chiffres vérifiables, du code qui tourne.

Prochaines étapes · De votre courriel à la livraison

Comment ça se passe

  1. Vous m’écrivez

    Le contexte, le problème, l’échéance si vous en avez une. Le formulaire prépare le courriel pour vous.

  2. On se parle trente minutes

    Je pose les questions qui évitent les mauvaises surprises : qui utilise l’outil, quelles données, quels écrans, que faire en cas de conflit.

  3. Je vous envoie un devis écrit

    Livrables nommés, étapes datées, ce qui est inclus et ce qui ne l’est pas.

  4. Je livre par étapes

    Chaque étape arrive avec ses tests et son code à jour. Vous voyez le résultat fonctionner avant de passer à la suivante.
