Formats · Trois façons de travailler ensemble

Stage, contrat ou mandat

  • Stage de fin de DEC

    Dans une équipe de développement ou d’intelligence d’affaires. J’arrive avec un dépôt public, des tests qui passent et l’habitude d’écrire la règle métier avant l’écran.

  • Contrat à durée déterminée

    Développeur mobile, web ou backend, à temps plein ou partiel, sur un produit existant. Reprise d’un code, ajout de tests, livraison par jalons.

  • Mandat à la pige

    Un livrable précis : une application, une API, un tableau de bord, un configurateur, une mise en ligne propre. Devis écrit avant de commencer ; tarif selon le mandat.

Méthode · Écrite, appliquée à ce site

Ma liste de lancement

Avant de mettre quelque chose en ligne, je passe quatre listes. Ce site les a passées ; le dépôt les garde en tête de projet.

  • Le vrai site, pas la maquette

    Page 404, appel à l’action visible sans défiler, titre et description par page, image de partage, favicons, robots.txt, plan de site, texte alternatif sur chaque image, points de rupture mobiles, états de chargement et d’erreur, page de remerciement, politique de confidentialité, conditions, vraie adresse de contact.

  • Sécurité avant la mise en ligne

    Aucune clé dans le code ni dans Git, authentification côté serveur, accès verrouillé par enregistrement, requêtes paramétrées, entrées validées, contenu échappé, téléversements restreints, en-têtes de sécurité, HTTPS forcé, dépendances auditées.

  • Le légal qui protège le client

    Politique de confidentialité qui dit ce qui est collecté, les tiers, l’usage d’IA ; suppression des données sur demande ; aucun stockage public ; aucun faux témoignage ; résiliation aussi simple que l’inscription.

  • Une identité, pas un gabarit

    Pas de dégradés violents, pas de cartes partout, pas d’émojis en guise d’icônes, pas de texte de remplissage : une typographie choisie, des chiffres vérifiables, du code qui tourne.

Prochaines étapes · De ton courriel à la livraison

Comment ça commence

  1. Tu m’écris

    Le contexte, le problème, l’échéance si tu en as une. Le formulaire prépare le courriel.

  2. On se parle trente minutes

    Je pose les questions de grain : quelle donnée, quel utilisateur, quel écran, quelle vérité en cas de conflit.

  3. Je t’envoie un devis écrit

    Livrables nommés, jalons datés, ce qui est inclus et ce qui ne l’est pas.

  4. Je livre par jalons

    Chaque jalon arrive avec ses tests et son dépôt à jour. Tu vois le code tourner avant de payer le suivant.
